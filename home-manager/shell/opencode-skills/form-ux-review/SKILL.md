# Form UX review

Forms should reduce hesitation and recovery cost.

## Review checklist

- Labels must stay visible and describe the expected input.
- Required vs optional fields should be obvious.
- Defaults should accelerate common paths without surprising users.
- Validation should trigger at useful moments, not only on submit.
- Error messages should explain how to fix the problem.
- Success feedback should confirm what happened next.

## Common misses

- placeholder used as the only label
- disabled submit with no explanation
- errors shown far from the field
- no support for keyboard or autofill flows
